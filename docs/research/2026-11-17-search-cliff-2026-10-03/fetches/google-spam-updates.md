# Google Search Central — Spam updates

> Fetched 2026-11-17 (HTTP 200, read in full). Read because the 2026-10-03 drop falls inside the
> September 2026 spam update, and the dashboard entry links this page. No last-updated date was shown.

## What it says

- A spam update is a notable improvement to systems that run all the time: "we occasionally make
  notable improvements to how they work. When we do, we refer to this as a *spam update*", and
  "Google's automated systems to detect search spam are constantly operating."
- "SpamBrain is our AI-based spam-prevention system."
- Recovery: "Sites that see a change after a spam update should review our spam policies", and
  "Making changes may help a site improve if our automated systems learn over a period of months".
- Link spam is the exception: for a link spam update, "making changes might not generate an
  improvement".

## What it does not say

- Whether a site hit by a spam update is affected as a whole or page by page.
- How to tell from Search Console that a spam update affected a site. No report says so.
